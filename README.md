# OmaPress

A native, local-first publishing application for Omarchy.

OmaPress turns author-owned Markdown and media into a static publication, RSS, Atom and JSON feeds, and copy-ready X Articles. The desktop uses Qt 6 and QML; the publication engine is a Rust CLI.

Full version 1 implementation is in progress. The real Fixing Everything publication is maintained separately from this product repository.
